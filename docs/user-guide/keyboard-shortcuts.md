# Keyboard shortcuts

This page lists the keys VinaX listens for in a browser, when a key is ignored, how to open the shortcut list inside the app, and the mouse and touch gestures that do the same jobs. The playback shortcuts and the in-app shortcut list are not available in the Android app.

## Open the shortcut list in the app

- Press `?` on any page with the player.
- Or open **Settings → Help & about → Keyboard shortcuts**.

Press `?` again or `Esc` to close it. The list shows the playback keys from the next section. It prints the letters as capitals, but you press the plain key without `Shift`.

## Playback

| Key | Action |
|---|---|
| `Space` | Play or pause |
| `→` | Forward 10 seconds |
| `←` | Back 10 seconds |
| `↑` | Volume up 5% |
| `↓` | Volume down 5% |
| `n` | Next song |
| `p` | Previous song |
| `m` | Mute or unmute |
| `s` | Shuffle on or off |
| `r` | Cycle repeat |
| `f` | Like or unlike the current song |
| `?` | Show or hide the shortcut list |

## When a key is ignored

- While you type in a text field, a text area or a drop-down list.
- Anywhere inside an open dialog.
- `Space`, `Enter`, the arrow keys, `Home`, `End`, `Page Up` and `Page Down` belong to a focused button, link, slider, tab, switch, checkbox or menu item. `Space` on a button presses that button and does not also pause the music. Letter keys still work there.
- Any combination with `Ctrl`, `⌘` or `Alt` is left to your browser, apart from the ones listed below.
- The playback keys work on the pages that show the player. On the VinaX AI page, use the keys in its own section.

## Command palette

| Key | Action |
|---|---|
| `Ctrl` + `K` or `⌘` + `K` | Open or close the command palette. Works while you are typing. |
| `↑` `↓` | Move through the results |
| `Enter` | Run the highlighted result |
| `Esc` | Close the palette |

The palette searches songs, pages and actions, such as Play / Pause, Next track, Toggle shuffle and Toggle theme.

## Search

| Key | Action |
|---|---|
| `↑` `↓` | Move through the suggestions under the search field |
| `Enter` | Pick the highlighted suggestion, or search for what you typed |
| `Esc` | Close the suggestions |

## Now Playing and the queue

| Key | Action |
|---|---|
| `Esc` | Leave Now Playing. If the controls are hidden, the first press brings them back. |
| `←` `→` on the Up next, Lyrics and Credits tabs | Move to the previous or next tab |
| `Home` `End` on those tabs | Jump to the first or last tab |
| `↑` `↓` on a queue row's handle | Move that song one place up or down |

Every drag on the Queue page also has a menu item: open a row's ⋯ menu for **Move up** and **Move down**.

## Flow

These keys apply while Flow is open. See [Flow](flow.md).

| Key | Action |
|---|---|
| `↓`, `Page Down` or `j` | Next song |
| `↑`, `Page Up` or `k` | Previous song |
| `Space` | Play or pause the song on screen |
| `Esc` | Close Flow |

## VinaX AI

| Key | Action |
|---|---|
| `Ctrl` + `K` or `⌘` + `K` | Start a new chat |
| `Ctrl` + `B` or `⌘` + `B` | Show or hide the chat list |
| `Esc` | Stop a reply |
| `Enter` | Send the message. `Shift` + `Enter` adds a new line. |
| `/` | Open the commands in the message box |

If you change the send setting in VinaX AI, the keys swap: `Ctrl` + `Enter` or `⌘` + `Enter` sends and `Enter` adds a new line. The hint under the message box always shows the current keys. See [VinaX AI](vinax-ai.md).

## Other places

| Key | Where | Action |
|---|---|---|
| `Esc` | A pop-up message | Dismiss the newest one, unless a sheet or menu is open |
| `Esc` | A festival greeting card | Close it |
| `→` or `Enter` | A tour | Next step |
| `←` | A tour | Previous step |
| `Esc` | A tour | Leave the tour |
| Arrow keys | **Settings → Appearance → App style** | Move between the app styles. See [App styles](app-styles.md). |

## Mouse

| Action | Result |
|---|---|
| Right-click a song | A short menu of quick actions for that song |
| Right-click elsewhere | A short menu of app shortcuts |
| `Shift` + right-click | Your browser's own menu |

Text fields always keep the browser's own menu. Press `Esc` or click outside to close the menu.

## Touch gestures

| Gesture | Action |
|---|---|
| Swipe a song row right | Add to queue |
| Swipe a song row left | Save to Listen Later |
| Swipe the Now Playing artwork left or right | Next or previous song |
| Double-tap the left or right edge of the artwork | Back or forward 10 seconds |
| Double-tap the centre of the artwork | Like the song |
| Pull down on Home | Refresh Home |
| Swipe a pop-up message down | Dismiss it |
| Long-press a recent search | Pin it |

For the player's controls, see [The player and the queue](player-and-queue.md).
