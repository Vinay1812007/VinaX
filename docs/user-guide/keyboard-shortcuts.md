# Keyboard shortcuts

This page lists every key the VinaX web app listens for, the rules for when a key is ignored, and the touch gestures that do the same jobs. Keyboard shortcuts are switched off inside the Android app.

## When a key is ignored

- While you type in a text field, a text area or a select, and anywhere inside an open dialog.
- `Space`, `Enter` and the arrow keys are left to a focused button, link, slider, tab, switch or menu item, so Space on a button presses the button and does not also pause the music. Letter keys still work there.
- Any combination with `Ctrl`, `⌘` or `Alt` is left to the browser, except `Ctrl/⌘ + K`.
- Letter shortcuts are lowercase: `n`, not `Shift + N`.

## Playback

| Key | Action |
|---|---|
| `Space` | Play / pause |
| `→` | Seek forward 10 seconds |
| `←` | Seek back 10 seconds |
| `↑` | Volume up 5% |
| `↓` | Volume down 5% |
| `n` | Next song (counts as a skip) |
| `p` | Previous song |
| `m` | Mute / unmute |
| `s` | Shuffle on / off |
| `r` | Cycle repeat |
| `f` | Like / unlike the current song |

## App

| Key | Action |
|---|---|
| `Ctrl/⌘ + K` | Open or close the command palette. Works while typing. Inside VinaX AI it starts a new chat instead. |
| `Ctrl/⌘ + B` | In VinaX AI, show or hide the chat list |
| `?` | Show the shortcut list |
| `Esc` | Close a sheet, dialog or menu; leave the full-screen player; stop an AI reply; leave a tutorial |
| `/` | In the VinaX AI composer, open the slash-command menu |
| `↑` `↓` `Enter` | Move and choose inside the command palette |
| `→` or `Enter`, `←` | Next and previous step in a live tutorial |

The command palette lists pages, player actions (including retuning the queue) and songs that match what you type.

## Touch gestures

| Gesture | Action |
|---|---|
| Long-press (or right-click) a song | Song menu |
| Swipe a song row right / left | Add to queue / Listen Later |
| Flick the player artwork up / down | Next / previous song |
| Double-tap the artwork's edges / centre | Seek / like |
| Pull down on Home | Refresh Home |
