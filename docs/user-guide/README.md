# VinaX listener guide

This folder is the guide for people who listen with VinaX. It covers setting up, playing music, steering what plays next, searching, keeping your library safe, listening with friends, the VinaX AI chat, keyboard shortcuts and the Android app. It describes VinaX 10.1: the 10.0 "Marigold" look and the frosted glass of 10.1. VinaX is free — no subscription, no sign-up — and nothing here needs a developer to make sense of; the engineering docs are one level up in the [docs index](../README.md).

The same material is inside the app: **Help** has six live tutorials that run on the real screens (one of them for Listen Together), searchable how-to guides and an FAQ. You can replay the welcome tour from Help at any time.
