# VinaX listener guide

This folder is the guide for people who listen with VinaX. It covers setting up, playing music, steering what plays next, searching, keeping your library safe, the VinaX AI chat, keyboard shortcuts and the Android app. It describes VinaX 7.1. Nothing here needs a developer to make sense of; the engineering docs are one level up in the [docs index](../README.md).

| Guide | What it answers |
|---|---|
| [Getting started](getting-started.md) | The welcome screen, the five destinations, the top bar, playing a first song |
| [The player and the queue](player-and-queue.md) | The next five, Pin a mood, Tune this queue, hand-queued songs, resume, sleep timer |
| [Discovery modes](discovery-modes.md) | Familiar, Balanced and Discover, and the other recommendation settings |
| [Search](search.md) | Searching as you type, lyrics search, sorting, recents, Discover's shortcut grid |
| [Library and backup](library-and-backup.md) | Favourites, playlists, Listen Later, backups, restore with Undo, moving devices |
| [VinaX AI](vinax-ai.md) | The chat: models, web search, slash commands, playable songs, what it sends |
| [Keyboard shortcuts](keyboard-shortcuts.md) | Every key the web app listens for, and the touch gestures |
| [Android](android.md) | What the Android app adds: background playback, downloads, updates |

The same material is inside the app: **Help** has live tutorials that run on the real screens, searchable how-to guides and an FAQ. You can replay the welcome tour from Help at any time.
