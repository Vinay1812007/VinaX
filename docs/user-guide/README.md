# VinaX listener guide

This folder is the guide for people who listen with VinaX. It covers setting up, playing music, steering what plays next, searching, changing the look, festival themes, keeping your library safe, listening with friends, the VinaX AI chat, keyboard shortcuts and the Android app. VinaX is free, with no subscription and no sign-up, and nothing here needs a developer to make sense of it; the engineering documents are one level up in the [docs index](../README.md).

| [Discovery modes](discovery-modes.md) | Familiar, Balanced and Discover, and the other recommendation settings |

| [Flow](flow.md) | The swipeable song feed |

The same material is inside the app. **Help** has nine live tutorials that run on the real screens, searchable how-to guides, answers to common questions and the shortcut list. You can replay the welcome tour from Help at any time.
