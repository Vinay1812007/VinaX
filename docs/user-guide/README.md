# VinaX — user guides

Short, practical guides to the parts of VinaX that reward reading a
paragraph or two. Everything is user-facing; nothing here needs a
developer to make sense of.

- [Replay & Resume](./replay-and-resume.md) — how VinaX remembers
  where you were in a song, and what the Continue Listening / On
  Repeat / Repeat Rewind shelves actually mean.
- [Import & Export Your Data](./import-export-your-data.md) —
  snapshot your favorites, history, taste and settings to a file
  you own; restore on any other device.
- [Keyboard shortcuts](./keyboard-shortcuts.md) — full list of the
  key bindings on the desktop web app.

Design & engineering docs live one level up (`docs/design-system.md`,
`docs/fcm-push-setup.md`, `docs/qa-device-script.md`, etc.).
