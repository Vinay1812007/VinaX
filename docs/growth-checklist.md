# VinaX — Growth & SEO Checklist

The code side is already strong: 28 prerendered routes, edge-rendered song/album/artist pages with real titles + OG tags + JSON-LD, and a live `sitemap.xml` index (daily song/album/artist/film maps). What's left is mostly **one-time owner actions** — nobody can do these but you.

## 1. Google Search Console (~15 min, highest impact)
- [ ] Go to search.google.com/search-console → Add property → **Domain** → `sirimillavinay.online`.
- [ ] Verify via DNS TXT record (Cloudflare → DNS → add the TXT Google shows you).
- [ ] Submit sitemap: `https://www.sirimillavinay.online/sitemap.xml`.
- [ ] After 2–3 days, check Pages → why any URLs aren't indexed; send me screenshots and I'll fix markup.

## 2. Bing Webmaster (~5 min)
- [ ] bing.com/webmasters → Import from Google Search Console (one click after #1).

## 3. Share test (~5 min)
- [ ] Paste a song link (e.g. `/song/...`) into WhatsApp, Telegram and X — each should show title + artwork card.
- [ ] Paste the home link the same way.
- [ ] Any of them look plain/broken → tell me which app + which URL; I'll fix the OG tags for that surface.

## 4. Zero-cost distribution
- [ ] Put the link in your and friends' Instagram/WhatsApp bios: "Free music, no login — sirimillavinay.online".
- [ ] Every APK share = a device that keeps the app; the in-app **Get the App** banner already converts web visitors.
- [ ] Ask 5 friends to enable 🔔 notifications — the daily song pick becomes your free re-engagement channel (capped at one/day by design).

## 5. Watch the flywheel (weekly, 2 min)
- [ ] Monday: read the **This week** digest on the admin Overview (listeners, new, plays, top search).
- [ ] Search Analytics → **zero-result searches** = what people want that they can't find → tell me recurring ones; we tune search for them.
- [ ] Engagement → skip rate per week — if a language's skip rate is high, we tune the home mix.

## 6. Later, when numbers justify it
- Custom OG share images per song (artwork + brand frame) — nice-to-have, ~1 release.
- A `/press` one-pager for blogs/colleges.
- Play Store listing (needs a developer account, $25 one-time) — the APK pipeline is already release-signed.
