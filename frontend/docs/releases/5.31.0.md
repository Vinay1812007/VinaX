- Shared listening workspace refresh, a new home hero and responsive Playlist Studio.

- Four-step welcome and a live Home Studio tutorial.

- Admin operational brief, home layout preview, presets, draft/published state, load-failure guard and duplicate-publish guard.
- Backend validation of published home configuration.
- Rewritten project/frontend documentation and current monorepo deployment instructions.

## Limits

Browser tests mock backend responses. They do not validate live catalog playback, AI provider credentials, Android native behavior or APK signing. A successful local build and push do not prove that Cloudflare deployed the commit. Verify remote CI, hosting deployment and live routes separately using the deployment guide.

The build still reports large lazy vendor chunks and an existing mixed static/dynamic telemetry import warning. The enforced first-load budget passes; these warnings should not be confused with a measured performance guarantee on every device.
